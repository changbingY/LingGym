### LingGym-Frq

Author: Max Khouvongsavanh
LingGym Authors: Changbing Yang, Franklin Ma, Freda Shi, and Jian Zhu.

Before Running this program, follow these instructions:

1. Get a [Cerebas API Key](https://cloud.cerebras.ai) and store it in .env, or run `export CEREBRAS_API_KEY="your-api-key-here"`
2. Download `Benchmark_multiple_choice` from [The LingGym Repository.](https://github.com/changbingY/LingGym)
3. Move it to this project folder and `cd` into it.
4. Install depenencies with `pip install -e .` or `uv sync`.
5. Run `uv run free_response_question_generation.py` or activate your virtual environment and run `python free_response_question_generation.py`.
